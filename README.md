## 핵심 결정 (v3 → 본 프로젝트)
1. **1과업 집중**: "분양 가능한 전원마을 실시간 찾기" (직전 최우수 '씨앗톡'과 차별)
2. **물 정보는 점수에서 분리**: 논가뭄지도 시군 가뭄 패널로만 (인과 오류 제거)
3. **결정론 우선, AI 최소**: 파싱·설명만 LLM, 점수·조회·검증은 결정론
4. **환각 0**: 모든 값을 API 필드에 바인딩, 미바인딩 차단
5. **프라이버시 우선**: 무저장 기본, 로컬 모델(확장) 옵션
