How it works

AI는 결정하지 않습니다.
근거를 정리해 보여줍니다.

자연어 한 문장이 근거 있는 후보 Top 3으로 바뀌기까지, 요청은 8단계의 결정론적 파이프라인을 지납니다. 순위를 만드는 것은 모델이 아니라 재현 가능한 코드입니다.

결정론 우선 · AI 최소 Evidence Binding 조건 자동완화 금지

Request pipeline

요청 처리
8단계

브라우저가 POST /api/search를 보내면, 각 단계는 자신이 실패했을 때 무엇을 할지까지 정의합니다. 어느 단계도 결과를 조용히 지어내지 않습니다.

  1. 1
    main.py · config.py

    데이터 모드 확인

    /api/health로 sample-mode 여부와 LLM 활성 상태를 반환합니다.

    실패 시 → 화면에 "데이터 상태 확인 불가" 표시

  2. 2
    guards.py

    입력 보호 (Guard)

    주민번호·연락처·이메일을 마스킹하고, 개행 우회를 포함한 prompt injection 패턴을 검사합니다.

    위험 입력 → 검색하지 않고 차단 사유 반환

  3. 3
    intent.py · llm_intent.py

    조건 해석 (Intent)

    지역·예산·분양단계·세대수·선호를 구조화된 ParsedQuery로 변환합니다.

    LLM 실패 → 규칙 파서로 폴백 · 조건 미인식 시 전체 노출 금지

  4. 4
    clients.py

    데이터 조회 (Client)

    분양정보를 필터링하고, 법정동코드로 마을현황을 결합하며, 시군 가뭄정보를 조회합니다.

    현재는 로컬 샘플 데이터 사용 · 상태 경고를 응답에 포함

  5. 5
    scoring.py

    필터 · 점수 (Scoring)

    진행단계 50%, 분양 가용성 30%, 선호 일치 20%로 적합도를 결정론적으로 계산합니다.

    잘못된 숫자는 None 처리 · 진행단계·세대수 조건은 임의 완화 없음

  6. 6
    evidence.py

    근거 검증 (Evidence Binding)

    카드에 노출하는 모든 수치를 api + field + value로 바인딩하고 누락을 검사합니다.

    미바인딩 수치 → 경고 · 확정값처럼 노출하지 않음

  7. 7
    orchestrator.py

    가뭄 참고 패널 분리

    상위 후보 시군의 농업가뭄 단계를 별도 패널로 표시합니다.

    가뭄 수치는 마을 적합도 점수에 반영하지 않음

  8. 8
    orchestrator.py · app.js

    응답 조립 · 화면 렌더링

    백엔드는 Top N·근거·경고·최종확인 고지를 SearchResponse로 조립하고, 프론트엔드는 로딩·성공·빈 결과·오류 상태를 렌더링합니다.

    데이터 없음 → 빈 결과와 다음 검색 안내 반환

Deterministic scoring

순위는 코드가 계산합니다. 언제나 같은 입력, 같은 결과.

적합도 = 0.5 × 진행단계 + 0.3 × 분양 가용성 + 0.2 × 선호 일치도
50%진행단계

분양중 1.0 · 분양예정 0.6 · 분양완료 0.1. 지금 들어갈 수 있는지가 가장 무겁습니다.

30%분양 가용성

(100 − 분양율) ÷ 100. 분양율이 낮을수록 남은 세대가 많다는 뜻입니다.

20%선호 일치도

조용함·빈집·교통 등 마을현황 자원과의 매칭 비율. 물 사정은 여기 포함하지 않습니다.

Design principles

여섯 가지 설계 원칙

01

결정론 우선, AI 최소

필터·점수·결합·근거 검증은 코드로 재현합니다. LLM은 자연어 구조화만 맡고 순위는 만들지 않습니다.

02

Evidence Binding

화면의 수치는 api + field + value 근거가 있어야 합니다. 데이터에 없는 값은 모델이 보완하지 않습니다.

03

조건을 몰래 완화하지 않음

명시한 조건에 결과가 없으면 다른 단계·작은 지구를 대신 보여주지 않습니다. 빈 결과가 잘못된 추천보다 낫습니다.

04

상관관계와 인과관계 분리

시군 가뭄정보는 특정 마을의 물 사정을 증명하지 않습니다. 참고 패널에만 표시하고 점수에 반영하지 않습니다.

05

실패를 숨기지 않음

sample-mode 여부, 필터 불가 사유, LLM 폴백을 경고에 기록하고 모든 응답에 최종확인 문구를 부착합니다.

06

개인정보와 외부호출 경계

검색 문장은 저장하지 않고 PII를 마스킹합니다. 외부호출은 공공데이터 호스트 allowlist 안에서만 허용합니다.
